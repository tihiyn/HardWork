# Первый пример
Необходимо проверить, есть ли ребёнок у сотрудника.

## Было:

```java
import java.util.List;
import java.util.UUID;

public interface ChildRepository extends JpaRepository<Child, UUID> {
    List<Child> findAllByPersonId(UUID personId);
}

@Service
@RequiredArgsConstructor
public class ChildService {
    private final ChildRepository childRepository;

    public boolean existsForPerson(UUID memberId, UUID personId) {
        return childRepository.findAllByPersonId(personId).stream()
            .anyMatch(child -> memberId.equals(child.getMemberId()));
    }
}
```

## Стало:

```java
import java.util.UUID;

public interface ChildRepository extends JpaRepository<Child, UUID> {
    boolean existsByMemberIdAndPersonId(UUID memberId, UUID personId);
}

@Service
@RequiredArgsConstructor
public class ChildService {
    private final ChildRepository childRepository;

    public boolean existsForPerson(UUID memberId, UUID personId) {
        return childRepository.existsByMemberIdAndPersonId(memberId, personId);
    }
}
```

На тестовых данных (10000 сотрудников, по 2 ребёнка в среднем на каждого) разница по производительность составила 5-9%.

# Второй пример
Необходимо получить точки маршрута (GPS-трек) для набора поездок, например, всех поездок водителя за смену.

## Было:

```java
@Service
@RequiredArgsConstructor
public class TripProvider {
    private final TripRepository r;
    private final VehicleLocationCachedRepository vlcr;
    private final TripService ts;

    public List<GeoJsonFeatureCollection> findTripsForMap(List<Long> tIds) {
        Map<Long, List<VehicleLocation>> tMap = new HashMap<>();
        for (Long tId : tIds) {
            Trip t = r.findById(tId).orElse(null);
            if (t != null) {
                List<VehicleLocation> locs = vlcr.findAllBetween(t.getVehicle(), t.getBegin(), t.getEnd());
                tMap.put(tId, locs);
            }
        }
        return ts.convertToGeoJson(tMap);
    }
}
```

## Стало:

```java
public interface TripLocationRow {
    Long getTripId();
    VehicleLocation getLocation();
}

public interface TripRepository extends JpaRepository<Trip, Long> {
    @Query("""
        SELECT t.id as tripId, vl as location
        FROM Trip t
        LEFT JOIN VehicleLocation vl
            ON vl.vehicle = t.vehicle AND vl.timestamp BETWEEN t.begin AND t.end
        WHERE t.id IN :tripIds
        """)
    List<TripLocationRow> findLocationsForTrips(@Param("tripIds") List<Long> tripIds);
}

@Service
@RequiredArgsConstructor
public class TripProvider {
    private final TripRepository r;
    private final TripService ts;

    public List<GeoJsonFeatureCollection> findTripsForMap(List<Long> tIds) {
        Map<Long, List<VehicleLocation>> tMap = r.findLocationsForTrips(tIds).stream()
            .collect(Collectors.groupingBy(
                TripLocationRow::getTripId,
                LinkedHashMap::new,
                Collectors.mapping(TripLocationRow::getLocation, Collectors.toList())
            ));
        tMap.replaceAll((tId, locs) -> locs.stream().filter(Objects::nonNull).toList());
        return ts.convertToGeoJson(tMap);
    }
}
```

На тестовых данных (500 поездок, примерно 10 точек на поездку) время выполнения снизилось со 133 мс до 17.7 мс.

# Третий пример
Необходимо построить отчёт «количество автомобилей предприятия по годам выпуска» за период.

## Было:

```java
@Service
public class ReportService {
    public ProductionYearReport buildProductionYearReport(Enterprise e, Integer sYear, Integer bYear) {
        Map<Integer, Long> res = e.getVehicles().stream()
            .map(Vehicle::getProductionYear)
            .filter(year -> year >= sYear && year <= bYear)
            .collect(Collectors.groupingBy(num -> num, Collectors.counting()))
            .entrySet().stream()
            .sorted(Map.Entry.comparingByKey())
            .collect(Collectors.toMap(Map.Entry::getKey, Map.Entry::getValue, (a, b) -> a, LinkedHashMap::new));
        ProductionYearReport r = new ProductionYearReport();
        r.setEnterpriseId(e.getId());
        r.setResult(res);
        return r;
    }
}
```

## Стало:

```java
public interface ProductionYearCount {
    Integer getYear();
    Long getCnt();
}

public interface VehicleRepository extends JpaRepository<Vehicle, Long> {
    @Query("""
        SELECT v.productionYear AS year, COUNT(v) AS cnt
        FROM Vehicle v
        WHERE v.enterprise.id = :enterpriseId AND v.productionYear BETWEEN :startYear AND :endYear
        GROUP BY v.productionYear
        ORDER BY v.productionYear
        """)
    List<ProductionYearCount> countByProductionYear(@Param("enterpriseId") Long enterpriseId,
                                                    @Param("startYear") Integer startYear,
                                                    @Param("endYear") Integer endYear);
}

@Service
@RequiredArgsConstructor
public class ReportService {
    private final VehicleRepository vr;

    public ProductionYearReport buildProductionYearReport(Enterprise e, Integer sYear, Integer bYear) {
        List<ProductionYearCount> counts = vr.countByProductionYear(e.getId(), sYear, bYear);
        Map<Integer, Long> res = counts.stream()
            .collect(Collectors.toMap(ProductionYearCount::year, ProductionYearCount::cnt,
                (a, b) -> a, LinkedHashMap::new));
        ProductionYearReport r = new ProductionYearReport();
        r.setEnterpriseId(e.getId());
        r.setResult(res);
        return r;
    }
}
```

На тестовых данных (20 000 автомобилей на предприятии, диапазон - 2000-2020) время выполнения снизилось с 12 мс до 6.35 мс.
